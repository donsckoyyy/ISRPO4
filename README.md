# ISRPO4 | Unit-тесты для функций

Учебный проект для лабораторной работы №4 по дисциплине «Инструментальные средства разработки ПО». В нём находятся две функции на Python и unit-тесты к ним, написанные с помощью стандартной библиотеки `unittest`.

Функции перенесены из проекта лабораторной работы №2: [ISRPO2](https://github.com/donsckoyyy/ISRPO2).

## Что входит в проект?

- `source/` | Папка с исходным кодом
  - `square.py` | Возведение числа в квадрат
  - `add_binary.py` | Сложение двух чисел и вывод результата в двоичной записи
- `tests/` | Папка с unit-тестами
  - `__init__.py` | Пустой файл, помечает папку как Python-пакет, чтобы `unittest` нашёл тесты
  - `test_square.py` | Тесты для функции `square`
  - `test_add_binary.py` | Тесты для функции `add_binary`
- `docs/` | Документация
  - `History.md` | История изменений проекта
- `README.md` | Описание проекта

## Функции

| Функция | Файл | Что делает? | Пример вызова: |
|---|---|---|---|
| **`square(n)`** | `source/square.py` | Принимает число `n`, возвращает его квадрат | `square(5)` => `25` |
| **`add_binary(a, b)`** | `source/add_binary.py` | Принимает два десятичных числа `a` `b`, возвращает их сумму в виде двоичной строки | `add_binary(7, 8)` => `'1111'` |

**Примечание:** функция `add_binary` возвращает `str`, а не `int`.

## Пример использования

Запускать из корня репозитория:

```python
from source.square import square
from source.add_binary import add_binary

print(square(5))         # => 25
print(add_binary(7, 8))  # => '1111'
```

## Запуск тестов

Из корня репозитория:

```
python3 -m unittest -v
```

Ожидаемый результат:

```
Ran 12 tests
OK (expected failures=1)
```

| Тестовый класс | Что проверяет |
|---|---|
| `SquareTestCase` | положительные и отрицательные числа, ноль, дробные числа, числовые строки (ожидается `TypeError`), `bool` |
| `AddBinaryTestCase` | положительные числа, нулевая сумма, разные знаки слагаемых, отрицательная сумма, дробные числа и строки (ожидается `TypeError`), `bool` |

## Известные дефекты

| Функция | Входные данные | Ожидается | Фактически | Тест |
|---|---|---|---|---|
| `add_binary` | отрицательная сумма, например `add_binary(-5, 2)` | `'-11'` | `'b11'` | `test_ifSumIsNegative_add_binary` |

**Причина:** срез `[2:]` рассчитан на префикс `0b` длиной 2 символа, а у отрицательных чисел префикс `-0b` длиной 3 символа. Дефект найден тестами и задокументирован, код функции не изменялся. Тест помечен декоратором `@unittest.expectedFailure`, поэтому прогон остаётся успешным (`OK (expected failures=1)`). Если дефект исправят, тест сообщит об этом как `unexpected success`.
